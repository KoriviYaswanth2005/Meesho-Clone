## 📌 About The Project

**Meesho Clone** is a modern front-end e-commerce website developed as a learning and portfolio project.

The project recreates the experience of a modern online shopping platform with a visually attractive interface, responsive layouts, interactive components, animations, transitions and multiple shopping-related pages.

The website is designed to demonstrate practical front-end development skills including HTML5, CSS3, JavaScript, Bootstrap, responsive design and UI/UX development.
